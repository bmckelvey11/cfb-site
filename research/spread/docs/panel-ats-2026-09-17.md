# Does any single panel model have an ATS edge? — 2026-09-17

**EXPLORATORY.** Not registered in `prereg-line-movement.md`. Written because
`panel-vs-line-2026-09-17.md` leaned on RMSE, and **RMSE is a weak test of bettability**.

## Why this study exists

The RMSE study found no panel column beats the market line. That is not the same as "no column
is bettable", and the earlier document framed it too strongly. RMSE is squared, symmetric, and
averaged over every game, so it is dominated by the middle of the distribution. A bet needs only
the **sign** of the disagreement to be right, only on the **games you choose**, and only
**52.381%** of the time. A model can be worse on average and still profitable on a subset.

So this asks the betting question directly, per model: bet the side the model favours when it
disagrees with the line by at least a threshold.

## Answer: the broad null holds. Nothing clears, short-lived models included.

### The sweep

141 models × thresholds {1, 2, 3} points, cells with ≥ 200 bets. Season-cluster bootstrap SE,
Benjamini-Hochberg q-values across the whole family (`base.bh_qvalues`), pushes dropped.

| | value |
|---|---|
| cells with ≥ 200 bets | 436 (148 models) |
| of those, with enough season clusters for a valid SE | **231** |
| surviving BH q < 0.10 | **0** |
| pooled ATS across all cells | **0.4982** |
| median cell ATS | 0.4980 |

The panel as a whole sits at coin-flip minus vig, exactly as the RMSE study implied. 205 cells
have too few seasons for a season-cluster SE; the week-clustered run below tests all 436.

*(The floor was `MIN_CLUSTERS = 3` when this study was first run, which admitted 330 cells and
one BH survivor. Raising it to 6 — for the reasons below — drops that survivor on the season
path too, so the retraction is now enforced by the code rather than only described here.)*

### Correction: the season-clustered survivor was an artifact

An earlier version of this document reported `linecrunch` at a 3-point threshold as a surviving
cell — 1,185 bets, 0.5418 ATS, BH q = 0.0026 — and presented it as a concrete case of a model
that loses on RMSE but wins ATS. **That was a false positive, and it is retracted.**

`linecrunch` covered only 2015–2017, so its season-cluster bootstrap resampled **three** units
whose season ATS values (0.5530, 0.5294, 0.5427) happen to be tightly grouped. A bootstrap over
three similar numbers cannot generate spread, so it returned an SE of 0.0055 — far too small.
`MIN_CLUSTERS` was 3 at the time, so the guard let it through. **It is now 6**, and this cell
returns no SE at all on the season path.

Re-clustering by **season-week** gives 47 clusters on the same bets:

| cluster unit | clusters | SE | z | BH q |
|---|---|---|---|---|
| season | 3 | 0.0055 | 3.28 | 0.0026 |
| **week** | **47** | **0.0137** | **1.31** | **0.2237** |

The week SE is 2.5x the season SE. Across the 330 cells testable both ways the two agree closely
(median ratio 1.01, week larger in 168 of 330), so this is not a systematic difference between
the units — it is specific to cells with very few season clusters, where the season bootstrap is
degenerate. `linecrunch` is the extreme case.

### The floor this changed

Checking every cell testable both ways against the many-cluster week benchmark, by how many
seasons the cell covers:

| seasons | cells | share with season SE off by > 30% | worst ratio |
|---|---|---|---|
| 3 | 39 | **59%** | **5.24×** |
| 4–5 | 60 | **45%** | **7.07×** |
| 6–7 | 24 | 29% | 1.52× |
| 8–9 | 27 | 30% | 2.02× |
| 10–12 | 48 | 19% | 1.90× |
| 13+ | 132 | 7.6% | 1.58× |

The break is in the **worst case**, not the median: below 6 seasons the season bootstrap can be
off by a factor of 5–7, and from 6 on the worst case is 2.0×. `base.MIN_CLUSTERS` was therefore
raised **3 → 6** on 2026-09-17.

Two things that number is not. It is **not** amendment B3's 8 — B3 is a stopping rule for a
confirmatory verdict on a preregistered hypothesis, a different question from when a bootstrap CI
is trustworthy. And it is **not** a derived threshold; it is a judgment call on the table above,
which degrades continuously rather than cliff-edging.

Two consequences recorded elsewhere: `phwin-moneyline-2026-09-17.md` has five seasons and now
clusters by week, which widened two intervals enough to withdraw a significance claim; and
`eval_model_columns_ats.py`'s `MIN_SEASONS` was **decoupled** from this constant and pinned at 3,
because there it is a coverage screen declared before scoring, not an inference floor.

### The full sweep under week clustering

Week clusters make **every** cell testable, including the 106 short-lived models that had no
valid season SE. Minimum 6 week clusters, median 86.

| | season clusters | week clusters |
|---|---|---|
| cells with a valid SE | 330 of 436 | **436 of 436** |
| above break-even | 17 | 17 |
| above break-even with raw p < 0.05 | 1 | **0** |
| **surviving BH q < 0.10** | 1 | **0** |

**Nothing survives.** The best short-lived candidates fail on their own terms once they have an
interval: `lineald` 0.5535 on 215 bets (8 clusters, p = 0.32), `linefluker` 0.5478 on 345 (17
clusters, p = 0.40), `lineed` at 2 points 0.5456 on 867 (31 clusters, p = 0.085, q = 0.11 — the
closest thing to a survivor, and it does not clear).

17 of 436 cells above break-even is about what chance produces when the true rate sits near 0.500
and the bar is 0.5238.

## The methodological point still stands

The objection that prompted this study — **beating the close on RMSE is not the test that
matters** — remains correct, and this study exists because of it. RMSE is squared, symmetric and
averaged over every game; bettability is about the sign of the disagreement on a chosen subset.
Those are different properties and they can come apart.

What changed is that the panel does not, on this evidence, contain a column where they do come
apart. The right test was run and it returned the same null the RMSE study did. That is a
stronger result than the RMSE study alone could support, and it was worth the work to get it.

A caveat on cluster choice, since it decided the headline: week clusters ignore season-regime
correlation and are in general the less conservative unit. They are used here because the
alternative for short-lived models is no test at all, and because at 3 season clusters the
season bootstrap is demonstrably worse. Where a cell has many seasons, both units agree.

## What this does not support

- **Not a retraction of the RMSE study.** Its measurements stand; the correction is to its
  framing, which treated RMSE ranking as sufficient to dismiss bettability. It is not, and
  `panel-vs-line-2026-09-17.md` now carries a pointer here.
- **Not proof that no panel column is bettable.** It is proof that none clears a BH-corrected bar
  on this data with these thresholds. Absence of a surviving cell across 436 tries is meaningful
  evidence, but not the same as a demonstrated null for every possible subset or rule.
- **Not a claim the panel is bettable.** 17 of 436 cells above break-even, none surviving BH,
  pooled 0.4982. The broad null is if anything reinforced by testing it the right way.
- **Not a version A or B read.** Amendment B3's stopping rule is untouched.
- **Not a statement about E4**, which forecasts line *movement* from the opener, a different
  estimand.

## Method

Data: `data/ingest/prediction_tracker_lines.csv`, all seasons, `match_status == 'matched'`,
margins oriented to PT's home team by `base.load()`. `MARKET_LINES` excluded.

The model implies a home margin of `-model`, the market `-line`, so the model favours **home**
iff `model - line < 0`. Home covers iff `y + line > 0`; pushes dropped. Cells need ≥ 200 bets
(`--min-bets`) and at least `base.MIN_CLUSTERS` clusters for a valid SE.

```bash
python research/spread/scripts/eval_panel_ats.py                  # season clusters
python research/spread/scripts/eval_panel_ats.py --cluster week   # the headline run
```

Writes `data/processed/panel_ats.json` (season) or `panel_ats_week.json` (week),
including every cell with its cluster count and q-value.
