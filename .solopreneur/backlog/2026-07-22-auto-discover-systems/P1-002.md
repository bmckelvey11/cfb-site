## Description
Surfaces `source="search"` provenance in the two existing web surfaces (My Systems dashboard table, `/compare` picker) with a neutral badge and "N candidates tested" line, per the spec's explicit color/placement constraints. No separate design mockup needed — the badge/CSS spec below is precise enough to build directly from.

## Acceptance Criteria
- [ ] Dashboard My Systems table (`dashboard.html`, `system-cell`): a search-found system shows a small **neutral-colored** "Search" badge inline with the name — explicitly not red/green (those colors are reserved for profit/loss elsewhere in the UI).
- [ ] Same row shows a "N candidates tested" line in the **same subtext slot** the existing `theory_line` uses (i.e. the `<p class="system-theory">`-equivalent slot at `dashboard.html:67-78`, not a new layout region).
- [ ] "Candidates tested" renders **near but visually separate from** the `stat-chips` row — it is provenance metadata, not a graded stat, and must not be styled/rendered as a chip.
- [ ] `/compare` picker (`compare.html:27-29`, currently bare checkbox + name) gets the **same badge treatment** as the dashboard table — a user must not be able to select a search-found system into a comparison without seeing the disclosure. Badge must render inside the `.check` label without breaking the `:has(input:checked)` CSS selector at `styles.css:182` (depends on the label's direct-children structure).
- [ ] Manual systems (`source="manual"` or missing) show **neither** the badge nor the candidates-tested line, in both surfaces.
- [ ] One new CSS rule `.badge-search` added — no new templates or screens introduced. There is currently zero existing `.badge` CSS anywhere in the codebase (confirmed via grep) — this is a net-new small component: small pill, neutral background (not the existing `.positive`/`.negative` colors), small font-size, inline-block next to the system name.
- [ ] `/compare` runs a search-found system through the **same `run_backtest` column** as any saved system — no special-cased evaluation path for search-sourced systems.
- [ ] `tests/test_web.py` / `tests/test_web_compare.py` gain: dashboard shows badge + candidate count for `source="search"` rows and omits both for manual rows; compare picker shows badge for search-sourced systems and omits it for manual; compare run produces identical-shape output regardless of source.
