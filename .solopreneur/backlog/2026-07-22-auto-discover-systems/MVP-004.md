## Description
Takes the top-K in-sample survivors from MVP-003, runs each through one full `run_backtest` on holdout data only, drops zero-holdout-bet finalists, and applies MVP-001's BH correction across the remaining finalists' holdout analytic p-values. Assembles the final structured search result (candidates_tested, finalists_graded, per-candidate stats, raw/corrected p, significance).

## Acceptance Criteria
- [ ] Holdout data is touched **exactly once**, here, after finalist identities are already fixed by MVP-003 — no code path in this ticket feeds back into candidate selection/ranking.
- [ ] Each of the K survivors receives exactly one full `run_backtest` call, on the holdout-only split. Full `run_backtest` call count for the whole search run is **at most `finalists_graded` (≤ top_k)** — never once per candidate evaluated during search.
- [ ] A finalist matching zero games in the holdout set is **excluded from results entirely** — not shown with a grade on a near-zero sample.
- [ ] BH correction runs as a single batch over **all K finalists' holdout analytic p-values** — using MVP-001's `bh_correct`, batch size = K (finalists actually graded, post zero-holdout-bet exclusion), explicitly **not** N (candidates_tested).
- [ ] BH input is the **analytic** p-value computed on holdout counts (MVP-001's helper) — **not** the permutation p-value from `run_backtest`'s `SystemStats.permutation_p_value`. The full `run_backtest`'s permutation p-value and letter `grade` are retained and reported as descriptive secondary statistics only, uninvolved in the BH batch.
- [ ] Each result carries three separate fields: `raw_p`, `corrected_p`, `bh_significant` — attached per candidate, never merged into or replacing `compute_grade`'s output.
- [ ] Output reports both `candidates_tested=N` (from MVP-003, provenance) and `finalists_graded=K` (count after zero-holdout-bet exclusion) as distinct fields.
- [ ] `tests/test_search.py` gains: holdout-cannot-alter-finalist-identity test (fixture where a candidate would rank differently if holdout leaked into MVP-003, assert it doesn't); zero-holdout-bet-finalist-omitted test; full-`run_backtest`-call-count-at-most-K test; BH-batch-size-is-K-not-N test.
