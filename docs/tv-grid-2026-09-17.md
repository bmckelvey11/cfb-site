# Weekly TV grid

**Question.** Show a week's FBS slate the way a TV guide does: network rows, kickoff-time
columns, one card per game with logos, rank, spread, total, network, and forecast weather.
Modelled on the IRON Football Saturday grid.

**Script.** `scripts/tv_grid.py` (`--season`, `--week`; defaults to the current season
and the next week with an unplayed FBS game). `scripts/tv_grid.cmd` refreshes CFBD
weather + media first, then renders. Tests: `tests/test_tv_grid.py`.

**Output.** `data/exports/tv_grid_<season>_wk<NN>.html`, logos cached once in
`data/exports/logos/`. `data/` is gitignored; nothing rendered is committed. Serve
`data/exports` with the `Exports (static)` entry in `.claude/launch.json` to preview.

## Sources per field (all local, as of 2026-09-17)

| Field | Source | Rule |
| --- | --- | --- |
| Games | `stg.games` | `homeClassification='fbs'`, regular season, the week (75 games in 2026 wk3) |
| Network | `stg.media` | tv outlet → row (`SEC Network`→`SECN` etc.); tv + web → tv row with the streamer as a badge (`NBC / Peacock`); web-only → compact STREAMING band |
| Spread, total | `core.fact_game_line` | median across `provider_key` books via `normalize.median_line` (see `docs/median-line-2026-09-17.md`); spread printed beside the favourite (`PK` at zero); `O/U` sits in the card footer with the kickoff time |
| Rank | `stg.rankings__polls__polls_ranks`, `stg.massey_editions` | `#AP · M<cmp_rank>`: AP Top 25 for the game week, Massey composite from the latest edition dated before the week's first kickoff. FCS opponents: `FCS #n` from the FCS Coaches Poll |
| Weather | `stg.weather` | CFBD forecast: `77°F · 0.15" · S 6 mph ↑ · Crosswind`. Precipitation is inches, not a chance. Arrow points where the wind blows *to*. `DOME` when `venues.dome` or `gameIndoors` |
| Wind vs field | `stg.venue_orientation` + `cfb_system_maker/wind.py` | relative label only when the OSM pitch match passes `orientation_is_usable` (67 of 75 wk3 venues) |
| Network logos | Wikimedia Commons, [Category:Logos of television channels in the United States by name](https://commons.wikimedia.org/wiki/Category:Logos_of_television_channels_in_the_United_States_by_name) | exact file titles in `NETWORK_LOGOS`, fetched once via `Special:FilePath` into `logos/net/`; text label when absent |
| Logos, colours | `data/raw/actionnetwork/scoreboard_<season>_wk<N>.json` | joined on kickoff (UTC) + team-name match; `AN_NAME_ALIASES` covers CFBD↔AN spellings (UMass, Miami (FL), FIU, ...) |

Row order: ABC, CBS, CW, FOX, NBC · ESPN, ESPN2, ESPNU · ACCN, BTN, CBSSN, FS1, SECN, TNT,
USA · unknown tv outlets alphabetically · STREAMING. Cards span 3.5 h (2 h in the
streaming band); overlapping cards on one row stack via a greedy interval packer.

## What it does not do

- Announcers: no local source. Not shown.
- BTN has no network logo on Commons; the Big Ten Conference mark stands in for that row.
- FCS-vs-FCS games: excluded (no line, no AN logo). The 4 FBS games with an FCS opponent
  stay in.
- Weather is CFBD's forecast at pull time. `stg.weather` only carries what the last
  `refresh_cfbd.py --only weather` fetched, so run `tv_grid.cmd`, not `tv_grid.py`, when
  freshness matters. The script warns per missing field.
- Massey has no FCS teams and lags a week (editions date Sunday, systems post by Monday
  night, `CFB-Massey-Weekly` pulls Tuesday 04:30; the daily rebuild loads it).
- California vs Wagner (2026 wk3) has no line at any book; the card shows none.
- Snapshot previews in the Claude browser pane cannot load relative logo paths; a real
  browser or the static server can.
