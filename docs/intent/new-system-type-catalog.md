# Intent: New System type catalog

Confirmed 2026-09-01 via interview-me.

- **Outcome:** Click **New System** → dedicated editor page (new URL, blank system). A **Spread / Total** dropdown at the top swaps the team-pair chips in place: spread stays **bet side / opponent**; totals relabels that pair to **home / away**. Stat filters stay shared. Over vs Under is its own control, not that pair.
- **User:** You, building systems.
- **Why now:** Totals don’t have “the team I’m betting,” so side/opponent labels are the wrong language for that catalog.
- **Success:** You can create a spread system and a totals system from that page, and the chips match the type without a second editor.
- **Constraint:** One editor. Changing the dropdown remaps labels on the same page — not a wizard, not a navigation.
- **Out of scope:** Two editors, two stat menus, a type-first step into the current editor, and home/away meaning “only home games.”
