## Phase Goal (user story)

**As a** bettor building a system, **I want to** filter on a team's prior-season offensive production (raw team wEPA from last year), **so that** I can express "last year's offense was strong/weak" edges without waiting for in-season data.

> Note: derived from Success Criterion 2. D-05 is a locked decision; per RESEARCH it is planned as a minimal DISTINCT signal (prior-season team offensive wEPA, not returning-player-weighted) to avoid redundancy with the existing returning_production features — it is not deferred.

Purpose: closes the D-05 locked decision with the smallest correct implementation. The single correctness risk is lookahead — using the SAME season's player totals pre-game bakes in the game being bet; prior-season aggregation is the honest pre-game surface (D-06).
Output: one new `team_preseason` FeatureDef + its enrich index + a sentinel-proven prior-season test.
