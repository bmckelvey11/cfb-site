<interface_notes>
Play text derivation is the one place a plausible-looking implementation is wrong. The system's declared side is NOT sufficient input on its own: the grading path normalizes the side first, inverting it when the system's fade flag is set, and applies the equivalent inversion for over/under on total systems. A fade system that MATCHES a home favorite is a bet AGAINST that favorite. Read the normalization at the top of `grade_bet` and its total-grading counterpart and run the same normalization for display.

The spread carried on a game record is always the HOME spread. The existing side-spread helper negates it for the away side. Use that helper rather than re-deriving the sign.
</interface_notes>
