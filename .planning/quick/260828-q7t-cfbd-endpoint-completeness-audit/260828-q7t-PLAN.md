# Quick Task: CFBD endpoint completeness audit (`scripts/audit_endpoints.py`)

`scripts/audit_coverage.py` walks the 63-entry `ENDPOINTS` registry and reports which
*files* are on disk. It cannot answer "do we cover every CFBD endpoint" — the registry is
its own universe. The authoritative universe is the live REST spec.

Probed before planning: `https://api.collegefootballdata.com/api-docs.json` returns 200
with exactly **74 paths**, matching the hand-audited number in `docs/data-coverage.md`.
That doc's 74 / 63 / 10 / 1 breakdown was a one-off manual diff; this makes it re-runnable.

**Verify command:** `python scripts/audit_endpoints.py` → partition closes at 74 with zero
unclassified, and `python -m pytest` still green.

## Tasks

1. `scripts/audit_endpoints.py` — three inputs, four buckets.
   - **Spec**: fetch `api-docs.json` (non-default `User-Agent`; this codebase already
     learned Cloudflare 403s urllib's default) or read a local file via `--spec`.
   - **Client**: `ast`-parse `cfbd-python/cfbd/api/*.py`. The path literal appears only in
     the `call_api('/teams/ats', 'GET', ...)` site inside each `*_with_http_info` variant,
     so map `(ApiClass, method_without_suffix) -> path`. Never infer a path from the class
     name — `TeamsApi` serves `/roster` and `/talent`.
   - **Registry**: `scrapers.ENDPOINTS`, keyed by `(api, method)`.
   - Buckets: `registered` / `client-only, unregistered` / `no client method` /
     `registry drift` (registry entry whose method is absent from the client, or whose
     resolved path is absent from the spec). Also report duplicate path→method hits and
     any non-GET verb, since the 74 denominator assumes one GET operation per path.
   - Exit 1 when drift or unclassified paths exist, so it can gate CI later.
2. `docs/data-coverage.md` — header currently names only `audit_coverage.py`; name both
   and say which question each answers.

## Done when

Script prints a partition summing to 74 with an empty drift bucket, and the three
non-registered counts match what `docs/data-coverage.md` claims (10 client-blocked,
1 deliberate). A partition that does not close is a finding to report, not a number to
massage.
