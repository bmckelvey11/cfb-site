# Quick Task: bring GraphQL into the endpoint coverage audit

`audit_endpoints.py` partitions the REST spec's 74 paths. GraphQL has the same flaw the
REST side had before it existed: `audit_coverage.py` compares `data/graphql/` against
`GQL_DEFAULT_TABLES`, a **hand-kept list of 24** — its own universe, not the API's.

Measured live before planning: introspection returns 38 root fields with scalar columns;
one (`athleteByPk`) is a Hasura per-key wrapper, leaving **37 real tables**. 13 sit outside
the default list:

- **11 lookup tables** already on disk, reachable only via `--tables` (`draftPosition`,
  `draftTeam`, `hometown`, `linesProvider`, `playerStatCategory`, `playerStatType`,
  `pollType`, `position`, `recruitPosition`, `recruitSchool`, `weatherCondition`) — all
  tiny, 2.5 KB to 2.2 MB.
- `gamePlayerStat` (~6.7M rows, multi-GB; on disk as per-season shards) and `scoreboard`
  (live endpoint, no historical value) — deliberate exclusions.

## Tasks

1. `graphql_client.py` — `GQL_DEFAULT_TABLES` 24 → **35** (the 11 lookups), and a
   `GQL_EXCLUDED` dict holding the two exclusions **with their reasons**. The rationale
   lives next to the list it modifies; the audit reads both rather than carrying its own
   copy, mirroring how the REST side sources `DELIBERATE`.
2. `audit_endpoints.py` — a GraphQL section: introspect, filter wrappers (printing what was
   filtered, so a schema shape change shows as a diff rather than a silently different
   denominator), then partition into in-defaults / documented-exclusion / unaccounted, and
   report on-disk status per table (counting `{table}_{season}.json` shards).
3. Exit-code rule: introspection failure (no Tier 3, no token, offline) is a **printed
   note, not exit 1** — otherwise the REST partition, which works offline via `--spec`,
   gets held hostage to a Patreon tier. Only a *reached-but-unaccounted* table fails.
4. Network-free test with a fake poster, as `tests/test_graphql.py` already does.
5. Re-run `audit_coverage.py` — extending the default list changes its "extra (not in
   default list)" line, and its per-season shard handling must not start reporting shards
   as extras.

## Done when

GraphQL partition closes at **35 in defaults + 2 documented exclusions = 37 introspected**,
zero unaccounted, and every in-defaults table has a file on disk. That last clause is the
one that catches a table added to the default list but never pulled.
