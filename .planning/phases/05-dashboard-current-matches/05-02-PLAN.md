<objective>
Unblock Current Matches by making the single authoritative matching path usable for unplayed games, and prove the performance-driven derivation the dashboard depends on.

`matches_system` currently returns `False` for every unplayed game because of a score guard at the top of the function. Per D-18, this is resolved with a `require_played` flag on the existing path, NOT a parallel matcher — Current Matches matches but never grades, so the single-path rule (Phase 4 D-15) is preserved rather than forked. Placeholder or fake scores are explicitly rejected: a placeholder in a grading path is how a fake result eventually gets counted as real.

The second half proves that filtering an all-time `bet_details` list on season yields exactly the bet set a season-restricted `run_backtest` would produce. The dashboard's timeframe tabs rely on this, and without it the dashboard would need one full `run_backtest` — including a 1000-iteration permutation test — per system per season tab.

Purpose: this is the blocking finding of the phase. Without it Current Matches renders zero rows forever, in every state, and no existing test catches it.
Output: a keyword flag on `matches_system`, and tests fixing both behaviors.
</objective>
