# Phase 4 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope note:** This phase replaces inline sidebar filter editing with one Bet Labs-style filter modal. It extends the existing Flask/Jinja/CSS design system from Phases 1–2 — **no new brand, no frontend framework, no chart library, no shadcn**. Tokens below reuse `cfb_system_maker/static/styles.css` unless marked as a new modal-only rule that still maps onto the same palette and 4px spacing grid.

**Locked sources:** CONTEXT D-01–D-23, REQUIREMENTS MODAL-01–06, `docs/bet-labs-parity-plan.md` §1.3 / §Phase 2, Phase 1 UI-SPEC token baseline.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — Flask + Jinja2 + vanilla CSS/JS + native `<dialog>`; no build step, no frontend framework (CONTEXT D-23). shadcn init gate does not apply: not React/Next.js/Vite (`components.json` absent). |
| Preset | not applicable |
| Component library | none — semantic HTML via Jinja (`templates/index.html`) plus one static JS module (`static/filter_modal.js`) |
| Icon library | none — text glyphs only (`✕` close/remove, Chart/List text toggle). No icon font. Charts remain hand-rolled inline SVG, matching `_range_chart` / cumulative-chart language. |
| Font | `Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif` — existing `:root` (`styles.css:15`). No new font. |

**Visual hierarchy (modal):** (1) Title + live Record/Money Won/ROI chips are the primary focal point; (2) exploratory distribution (chart or value table) is the secondary anchor — visually distinct from the header chips; (3) About Filter panel is tertiary supporting context on the right (desktop) or below (narrow).

**Shell constraint:** Keep the current sidebar + workspace layout (D-02). The modal overlays the dimmed page; it does not redesign the main editor.

## Spacing Scale

Declared values (multiples of 4) — applies to **new** modal/launcher surfaces. Do not refactor pre-existing sidebar/workspace paddings that already deviate from the grid.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon/glyph gaps; chip label-to-value internal nudge |
| sm | 8px | Chip-to-chip gap; toggle segment gap; table cell compact gap; About panel internal stack gap |
| md | 16px | Modal body padding; gap between header and exploration area; BETWEEN input group gap; search field margin |
| lg | 24px | Modal section gap (controls → chart/table); About panel padding; footer action bar padding |
| xl | 32px | Modal outer padding on desktop; gap between main column and About panel |
| 2xl | 48px | not used this phase |
| 3xl | 64px | not used this phase |

**Exceptions:**
- Modal max content width: **960px** (discretion; wide content + About). Viewport edge inset: **16px** on narrow screens.
- Dual-range track hit area: track visual height **4px**, thumb **16px**; interactive target for each handle remains ≥ **36px** (matches existing `.check` / remove-filter min-height convention). Do not invent a separate 44px touch-token unless implementing a mobile-only override later.
- Value table may use existing `th`/`td` padding `10px 12px` (legacy table rule) — do not restyle global tables to force 8pt purity.
- Backdrop click target is full-viewport; no padding token required.

## Typography

Reuses Phase 1 roles. Only 2 weights for **new** modal elements: **400** and **700**. Do not extend legacy `800` (button/pill/chip-label) to new modal chrome beyond reusing existing `.metrics span` / primary-button rules where those classes are literally reused.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Label | 12px | 700 | 1.2 | Chip labels (Record / Money Won / ROI), About Filter heading, table column headers (or reuse uppercase 11px `th` rule when using `.table-wrap`), perspective/Chart-List toggle labels |
| Body | 14px | 400 | 1.5 | About Filter definition text; empty/error/neutral explanatory copy; BETWEEN helper text; search placeholder; launcher row labels; Edit link |
| Heading | 20px | 700 | 1.2 | Modal title (filter display name) |
| Display (chip value) | 22px | 700 | 1.2 | Live Record / Money Won / ROI values inside modal header chips |

Footer actions reuse existing `button` rule: 14px / weight 800 (legacy primary button — allowed only because Save Filter is a primary `button` element matching Run/Save System).

## Color

Reuses `:root` tokens — **no new hex brand colors**. Modal-only surfaces map onto existing tokens.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--bg` `#f6f8fb` | Page remains visible under dimmed backdrop |
| Secondary (30%) | `--panel` `#ffffff`, `--panel-strong` `#f1f5f9` | Dialog surface (`--panel`); About panel / chip / table-header fills (`--panel-strong` or bordered `--panel`); launcher rows |
| Accent (10%) | `--accent` `#166f5b` (+ `--accent-dark` `#0d4f41` hover) | Save Filter button; selected dual-range span; positive Money/ROI; Chart/List active segment; checked categorical rows; focus ring accent; win-colored chart dots |
| Destructive/negative | `--loss` `#b42318` | Negative Money/ROI; loss-colored chart dots; close ✕ (non-destructive discard affordance, same as remove-filter) |
| Border / muted | `--border` `#d8e0ea`, `--muted` `#617086`, `--text` `#162033` | Dialog border, table rules, secondary Cancel button border, labels, About body, neutral Record chip |
| Backdrop | `rgba(22, 32, 51, 0.45)` | Dim overlay derived from `--text` `#162033` at 45% opacity (discretion) |
| Lookahead warning | Existing stale/warning language — amber `#fff4e5` / `#f0b429` border from `.stale-warning`, or the existing `.lookahead-warning` style if already distinct | Repeat analysis-only warning inside modal for `result_lookahead` filters (D-20) — reuse, do not invent a third warning palette |
| Loading affordance | `--muted` text + 0.55 opacity on chip values (not zeroed) | Live recalculation in flight (D-16) |

**Accent reserved for (explicit list — never “all interactive elements”):**
1. Primary **Save Filter** button (and its hover `--accent-dark`)
2. Positive signed Money Won / ROI chip values and matching chart dots (`.positive`)
3. Selected portion of the dual-handle range track
4. Active Chart/List (and perspective) segmented control state
5. Checked categorical row accent border/background (reuse `.check:has(input:checked)` green tint `#eef8f4` / `rgba(22, 111, 91, 0.35)`)
6. `:focus-visible` outline on modal controls (2px solid `--accent`)

**Not accent-colored:** Record chip (neutral fact), Cancel button, About panel chrome, backdrop, table chrome, launcher list, modal title.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | **Save Filter** |
| Secondary dismiss | **Cancel** |
| Close control | Visible glyph `✕` — `aria-label="Close filter dialog"` (same discard path as Cancel / Escape; D-04, D-21) |
| Sidebar launcher | Filter display name as button/label text (e.g. feature `label` or core name). No separate “Configure…” verb required. |
| Active-filter Edit | Visible text **Edit** — `aria-label="Edit filter: {sentence text}"` (Remove `✕` remains separate one-click; D-03) |
| Chart / List toggle | **Chart** / **List** (numeric filters; default Chart — D-09) |
| BETWEEN inputs | Literal chrome: `BETWEEN` `[min]` `AND` `[max]` (Bet Labs parity) |
| Perspective (team-scoped) | **Bet-side** / **Opponent** / **Either** (defaults: spread → Bet-side, total → Either; edit preserves committed — D-14) |
| Boolean rows | Exactly **Yes** and **No** (D-13) |
| About panel heading | **About Filter** |
| Value table columns | **Description** · **Record** · **ROI** · **Money** (D-11) |
| Search placeholder | `Search values` |
| Table footer (optional, if shown) | `Showing {visible} of {total}` (Bet Labs “Showing 1 to N of N” simplified; case-insensitive filter may shrink `visible`) |
| Empty domain heading | **No values in range** |
| Empty domain body | `No observed values remain after the rest of this system. Adjust other filters, or cancel.` Neutral chips: `0-0-0`, `$0`, `0%` (D-10). |
| No-match candidate (live chips) | Keep chips at `0-0-0` / `$0` / `0%` with helper: `No bets match this draft.` Do not show a broken chart; chart/table use empty-domain treatment. |
| Live loading | Keep last successful chip values visible; adjacent status text: `Updating…` (D-16). Do not flash zeros. |
| Live error | `Couldn’t update live stats.` + button **Retry** (D-17). Modal stays open; last successful chips remain. |
| Save disabled (invalid range) | No toast required; Save Filter `disabled` while min/max invalid or reversed (D-06). Optional inline hint under BETWEEN: `Max must be greater than or equal to min.` |
| Save disabled (awaiting validation) | Save stays disabled until latest draft has a successful server validation (D-17). No extra banner beyond `Updating…` / error+Retry. |
| Lookahead warning (modal) | Reuse sidebar wording: `lookahead — analysis only` (or the exact existing `.lookahead-warning` string) inside the modal body/About area for `result_lookahead` filters (D-20). |
| Progressive-enhancement fallback | No special marketing copy — conventional controls remain usable without JS (D-05). Do not show a “Enable JavaScript” dead-end. |
| Destructive confirmation | **None.** Cancel / Escape / ✕ discard an unsaved draft without a confirm dialog (draft was never committed). Remove on the sentence list remains a one-click URL change (Phase 1). No delete-system action in this phase. |

**Money / ROI formatting (modal chips):** Match main-page chip conventions — Record as `W-L-P`; Money Won as `$` at profit×100 with `+`/`−` and `.positive`/`.negative`; ROI as percent with two decimal places. Neutral zero state uses `$0` and `0%` without forced green/red.

## Interaction Contract — Modal Shell

| Behavior | Contract |
|----------|----------|
| Element | One reusable native `<dialog>` (`showModal()`), labelled by visible title (`aria-labelledby` pointing at the heading) |
| Open (add) | Sidebar launcher → clean draft at observed domain / default perspective (D-03, D-07, D-14) |
| Open (edit) | Active-filter **Edit** → same shell prefilled with committed bounds/selection/perspective (D-03) |
| Focus | Move focus into dialog on open (prefer first invalid control, else first range/search/checkbox, else Cancel); restore focus to the launching control on close (D-21) |
| Escape / Cancel / ✕ | Discard draft; leave `filters-form` and URL unchanged (D-04) |
| Backdrop click | **Does not** close, commit, or discard (D-21). Dialog stays open. |
| Save Filter | Enabled only when draft is locally valid **and** latest live validation succeeded; writes canonical controls into `filters-form`, closes dialog, submits existing full-page GET (D-04, D-17) |
| Animation | Discretion: ≤ **150ms** opacity fade on open/close. No bounce, no slide-from-bottom sheet on desktop. |
| Z-layer | Native top-layer via `showModal()`; do not hand-roll a competing page-wide focus trap |

### Desktop layout (≥ 901px, align with existing 900px breakpoint)

```
┌────────────────────────────────────────────────────────────┐
│ Title (left)     [Record] [Money Won] [ROI]   Chart│List  ✕│
├──────────────────────────────────────────────┬─────────────┤
│ Controls (slider/BETWEEN or search+table)    │ About Filter│
│ Exploration (chart default / list table)     │ definition  │
├──────────────────────────────────────────────┴─────────────┤
│                         Cancel     Save Filter             │
└────────────────────────────────────────────────────────────┘
```

- Main column ~70% / About ~30% with **32px** column gap (D-22).
- Footer actions right-aligned: Cancel (secondary) then Save Filter (primary).

### Narrow layout (≤ 900px)

- Stack: header → controls → exploration → About → actions (D-22).
- Actions remain visible without horizontal page overflow; value table scrolls horizontally inside a `.table-wrap`-style container.

## Interaction Contract — Numeric Filters

| Behavior | Contract |
|----------|----------|
| Controls | Dual native `input[type=range]` (overlaid) + synchronized number inputs in `BETWEEN [min] AND [max]` (D-06) |
| Sync | Slider ↔ numbers both directions; prevent crossing; Save disabled while invalid/reversed (D-06) |
| Open defaults | New: full observed domain. Edit: committed bounds (D-07) |
| View default | Chart; toggle to List (D-09) |
| Chart | SVG dots per value (or downsampled render points only); green/red via `.positive`/`.negative`; zero-line uses existing chart stroke; height **150px** (match `.range-chart svg`) |
| Downsampling | Visual only — must not change selected bounds or live header metrics (D-09) |
| List | Same columns as categorical table, rows = exact values with per-value Record/ROI/Money |
| Distribution semantics | Candidate filter removed; other system filters applied; header = system + draft (D-08, D-15) |

---

## Interaction Contract — Categorical / Boolean

| Behavior | Contract |
|----------|----------|
| Categorical | Searchable, sortable checkbox table: Description, Record, ROI, Money; multi-select → `in` (D-11) |
| Search | Client-side, case-insensitive over Description (D-12) |
| Sort default | Description ascending; Record/ROI/Money sortable both directions; `aria-sort` on active header; sort controls are `<button>`s (D-12, D-21) |
| Boolean | Same table language; exactly two single-choice rows Yes/No; Save requires one selection (D-13) |
| No free-text comma entry | Primary modal UI only — no comma-list text field as the main selector (D-11) |

---

## Interaction Contract — Live Metrics

| Behavior | Contract |
|----------|----------|
| Chips | Always Record, Money Won, ROI for `current system + modal draft` (D-15) |
| Debounce | ~**250ms**; abort prior fetch; ignore stale generations (D-16) |
| In flight | Last success stays visible + `Updating…` (D-16) |
| Failure | Inline error + **Retry**; no close; no form mutation; no zero-flash overwriting last success (D-17) |
| Authority | Server JSON only — never client-computed performance (D-15, D-18) |

---

## Interaction Contract — Sidebar Launchers & Fallback

| Behavior | Contract |
|----------|----------|
| JS enhanced | Sidebar filter constraints become grouped launchers; registry groups + `result_lookahead` quarantine styling remain (D-01, D-02) |
| Not modal filters | Bet type, spread/total side, position toggles, Fade, theory, load, Run System, Save System stay global (D-01) |
| No-JS | Canonical conventional controls remain in the DOM and usable; enhancement hides fallback only after successful JS init (D-05). Never hide fallback in base CSS before `.js` is applied. |

## UI Considerations

| Category | Element(s) | Status | Resolution |
|----------|------------|--------|------------|
| empty | Numeric/categorical domain with zero observed values | ✅ covered | Neutral chips + empty-domain copy; no broken SVG |
| empty | Live draft matches zero bets | ✅ covered | `0-0-0` / `$0` / `0%` + `No bets match this draft.` |
| loading | Live `/api/backtest` | ✅ covered | Last success + `Updating…` |
| error | Live request failure | ✅ covered | Inline error + Retry; Save gated |
| partial | Stale response race | ✅ covered | AbortController + generation check (research Pattern 2) |
| overflow | Wide value table on narrow screens | ✅ covered | Horizontal scroll inside modal table wrap; page does not grow sideways (D-22) |
| long-text | About Filter definitions | ✅ covered | Plain text via `textContent`/Jinja escape; wrap with normal/overflow-wrap; never HTML (D-19) |
| zero-one-many | Boolean Yes/No | ✅ covered | Exactly two rows; Save requires one |
| keyboard | Dialog + table sort + ranges | ✅ covered | Native dialog, button sort headers, native range inputs, Escape=Cancel, visible `:focus-visible` |
| progressive enhancement | Sidebar filters | ✅ covered | Launchers opt-in after JS; fallback controls remain |
