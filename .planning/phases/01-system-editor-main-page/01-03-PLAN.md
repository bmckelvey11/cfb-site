    1. `if system.favorite:` (only reachable meaningfully when bet_type=="spread", but the check itself only needs to be gated by an outer `if system.bet_type == "spread":` wrapping steps 1-2-5 as described next) — append `{"text": "the team is a favorite", "key": "favorite"}`.
    2. `if system.underdog:` -> `{"text": "the team is an underdog", "key": "underdog"}`.

    3. `if system.home:` -> `{"text": "home games only", "key": "home"}`.
    4. `if system.away:` -> `{"text": "away games only", "key": "away"}`.
    5. Spread range (inside the bet_type=="spread" gate): if both `min_spread`/`max_spread` are not None and equal -> `"the spread is exactly {_fmt_num(min_spread)}"`; both set and different -> `"the spread is between {_fmt_num(min_spread)} and {_fmt_num(max_spread)}"`; only min set -> `"the spread is at least {_fmt_num(min_spread)}"`; only max set -> `"the spread is at most {_fmt_num(max_spread)}"`; key `"spread_range"` for all four sub-cases; append nothing if neither is set.
    6. Total range (NOT gated by bet_type — always evaluated): same four sub-case structure as spread range but using `min_total`/`max_total`, text prefix "the total is ...", key `"total_range"`.
    7. For each of `(system.seasons, "season", "seasons")`, `(system.weeks, "week", "weeks")`, `(system.teams, "team", "teams")`, `(system.conferences, "conference", "conferences")`, `(system.providers, "provider", "providers")` in that exact order: if the set is non-empty, append `{"text": f"the {label} is {', '.join(str(v) for v in sorted(values))}", "key": key}`.
    8. For each `filt in system.feature_filters` (in tuple order): look up `feature = FEATURE_BY_KEY.get(filt.key)`; if `feature is None`, `continue` (silent skip, no sentence, no exception). Else branch on `(filt.op, feature.control)`: `("eq", "bool")` -> `f"{feature.label} is {'Yes' if filt.value else 'No'}"`; `("eq", "categorical")` -> `f"{feature.label} is {filt.value}"`; `("in", "categorical")` -> `f"{feature.label} is one of {', '.join(filt.value)}"`; `("gte", "numeric")` -> `f"{feature.label} is at least {_fmt_num(float(filt.value))}"`; `("lte", "numeric")` -> `f"{feature.label} is at most {_fmt_num(float(filt.value))}"`. Append `{"text": <text>, "key": f"ff:{filt.key}"}` for whichever branch matched; if none of the five (op, control) combinations match, skip silently (defensive, should not occur given the registry's fixed control/op vocabulary).
    Return `sentences`.
