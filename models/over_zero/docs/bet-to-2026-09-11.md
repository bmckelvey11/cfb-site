# Bet to column — September 11, 2026

Question: which total is the limit for an OVER signal remaining above 1.75 bias?

Implemented `bet_to_total` in `scripts/best_line_slate.py`. Higher totals reduce
censoring bias, so the useful cutoff is the highest qualifying total, not the
lowest. Integer bisection finds the final half-point strictly above threshold;
an exact equality does not qualify. Spread and fitted sigmas stay fixed. Each
book view uses its own spread; market-wide picks use the market spread. The
selected book-only qualifier retains its own cutoff when combined into Best lines.

The CSV includes `bet_to`; exported board JSON includes `betTo`. Both desktop
table and mobile cards show Bet to beside existing pricing/staking information.
The explanation states that spread changes require a new board and the existing
price limit of -120 remains applicable.

Data: fitted 12,988 games from 2013–2025, current slate at September 11 08:37 UTC,
85 market-priced upcoming games. All 59 qualifying entries across book views
passed cutoff and next-half-point boundary checks. Examples: Virginia 59.5,
Indiana 70.5, West Virginia 55.5. Eleven unique games remain on Best lines.

Verification: `scripts/verify_site_refresh.py` checks every exported cutoff,
brute-force grids, exact equality, both spread signs, an empty input and a case
where no nonnegative total qualifies. Existing game-view checks and production
build pass. Reproduce the board with `scripts/best_line_slate.py --json
models/over_zero/site/lib/board.json` from the repository root with CFB_DATA_ROOT.

These values are sensitivity cutoffs for the existing bias screen, not newly
validated profitability limits or guarantees of available prices.

## Editable spread follow-up

Added per-game, per-book-view spread edits and Reset. Only Bet to recalculates;
snapshot prices, bias, probability, and signal selection remain unchanged.
The generator exports 201 exact half-point cutoffs for absolute spreads 0–100,
calculated with the same fit. Input accepts signed half-point spreads from
-100 to +100; blank, non-half-point, and out-of-range values show no cutoff.
Home-team sign convention is explained beside the board instructions.

Market spread is now a separate column/card metric. It comes from the actual
market view even for book-only picks. Individual book views label their own
spread as Book spread. The editor defaults to the spread used by the qualifier.

Validation passed for all 201 cutoff boundaries, all market-spread references,
all 59 initial qualifying entries, changed spreads, both signs, invalid/blank
input, and bounds. `site/lib/bet-to.test.mjs` verifies browser lookup behavior;
`scripts/verify_site_refresh.py` checks the values against the Python model.
